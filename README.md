# 拍谷背景 · 动态背景板

拍吧唧、棉花娃娃、立牌等谷子时，用屏幕（加一面镜子）当背景板的网页。可以选颜色和特效，屏幕上会显示流动的光线、星星、羽毛等动画。

## 使用

- **直接用**：双击打开 `dist/index.html`（单文件、离线可用，可拷到平板/手机/电脑上）
- **开发**：`npm install && npm run dev`（同一局域网的手机/平板可访问终端显示的 Network 地址）
- **重新打包**：`npm run build` → `dist/index.html`

快捷键：`H` 面板 · `F` 全屏 · `空格` 暂停定格 · `R` 随机 · `←/→` 切换场景 · `Esc` 收起面板
闲置 3 秒后会自动隐藏按钮和鼠标指针，点一下背景就能收起设置面板。设置会自动保存在浏览器里。

## 拍摄小贴士

- 把屏幕亮度调高，关掉自动亮度和护眼/夜间模式，以免颜色偏黄
- 屏幕拍出摩尔纹时：让谷子离屏幕远一点、开大光圈虚化背景，或把「渲染精度」调低，画面会更柔和
- 想定格某一帧时按空格暂停
- 用浅色背景（樱花白、天空白、奶油、抹茶）配羽毛、光斑，适合拍日系清新风格

## 技术

- 原生 JS + [Vite](https://vite.dev/)，用 `vite-plugin-singlefile` 打包成一个 HTML 文件
- 背景：自己写的 WebGL 片元着色器（fbm 噪声、极光、焦散等）
- 粒子：[tsParticles](https://particles.js.org/) v3 完整包（旋转、翻滚、摇摆、闪烁等），羽毛/花瓣/爱心/泡泡/蝴蝶/星芒都是按当前配色实时生成的 SVG
- 流星、扫光、烟花、雨丝、涟漪：自己写的 Canvas 2D 动画（`src/canvasFx.js`）
- 用 Screen Wake Lock API 尽量让屏幕保持常亮
